Node.js Server Demo

This project was created for the Advanced Web Technology practical.

Objective

The objective of this practical is to create a basic web server using Node.js that responds to a browser request and displays:

Hello Javascript

Technologies Used

- Node.js
- JavaScript
- HTTP Module
- npm
- Git and GitHub

How to Run

1. Open the Project Folder

Open the project folder in the terminal:

cd node-server-demo

2. Start the Server

Run the following command:

node server.js

The terminal should display:

Server is running on port 3000

3. Open the Server in a Browser

Open the following address in a web browser:

http://localhost:3000

The browser will display:

Hello Javascript

4. Stop the Server

To stop the running server, press:

Ctrl + C

Expected Output

The server successfully displays:

Hello Javascript
